# MESBG Character Card Creator

A fully client-side character card generator for Middle-earth Strategy Battle Game (MESBG), built with React + Vite.

## 🌐 Live URL

**[https://taylortower.github.io/MESBG-Character-Creator-/](https://taylortower.github.io/MESBG-Character-Creator-/)**

## Features

- Create and customise MESBG character cards with real-time preview
- Edit all stats, wargear, heroic actions, and special rules
- Upload character artwork with position/scale controls
- Choose from colour presets or fully customise the colour scheme
- Export cards as PNG or PDF
- Save templates to browser storage
- Share cards via URL link
- Responsive design — works on mobile, tablet, and desktop

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

No backend required — everything runs client-side in the browser.
